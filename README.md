# P1 第06课：Vue作品门户

本课分支：p1-guide-06-v1.2。老师的资源目录是 kit-06-v12；starter 内是保留课堂任务的初稿。

## 本课只打开这一份手册

[统一实操手册：在线阅读与复制命令](统一实操手册.md) / [Word 阅读版](统一实操手册.docx)。

CMD 与 PowerShell 已合并成同一条步骤。通用命令只做一次；标有二选一时，只执行自己终端的一框。具体代码修改、验证和网站发布共用正文。

流程：Git clone 领取 → 准备自己的 p1-portfolio → 运行 → 修改指定文件 → 检查 → 提交 → 推送到本人成果仓库 → 网站发布。每步写明运行平台、目录、运行方法、命令说明与成功标志。

在 VS Code 中打开统一实操手册.md，按 Ctrl+Shift+V 预览；开发时打开用户目录下 web-work/p1-portfolio。只把 starter 导入自己的工程，不把老师的 .git 复制进去，也不把老师仓库设为自己的 origin。第 2 课起先提交、备份，再导入本课任务并恢复个人内容。

PPT 仍是课堂主线。现有 PPT 的命令页标注 PowerShell；CMD 学生在本手册同一任务下选 CMD 框，做完回到 PPT 继续。后续数据库教学按其他项目推进。
