# 一笺心意 v1.3 · 在线演示

《前端框架应用开发》项目 4 的成品演示站，由 `工程基线/` 构建而来（`npx vite build --base=./`）。

- 源码在同一仓库的 `p4-lesson-01` ~ `p4-lesson-03` 分支，以及课程仓库的 `13_项目4_一笺心意_完整课堂包/工程基线/`。
- 本站是**纯静态部署，没有后端**。没有连上生成服务时，页面会用内置的本地文案库出稿（810 种说法），产品照常可用。
- 分享链接把贺卡内容放在网址 `#` 之后，浏览器不会把这一段发给服务器，所以本站不保存任何人写的祝福。

这个分支由构建产物组成，不要在上面直接改代码。
