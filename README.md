# P1 第02课：响应式与打印

本课分支：p1-guide-02-v1.2。课堂主流程用 Git clone 领取资源，starter 是留有 TODO 的学生初稿。

## 选择一种终端，按对应手册操作

- **CMD（学生熟悉时优先）**：[在线实操手册](CMD实操手册.md) / [Word 版](CMD实操手册.docx)。
- **PowerShell**：[在线实操手册](实操手册.md) / [Word 版](实操手册.docx)。
- [怎样打开和区分两种终端](Windows终端选择与命令对照.md) / [Word 对照说明](Windows终端选择与命令对照.docx)。

两种手册使用同一个个人工程 p1-portfolio，不要各做一次。每份手册均包含运行平台、当前目录、输入方法、命令注释、成功标志和常见问题。CMD 使用 rem 注释，PowerShell 使用 # 注释。

## 目录用途

- starter：本课初稿，只从这里复制或导入自己的工程。
- CMD实操手册、实操手册：从领取、开发到提交和推送的完整说明。
- 操作命令：终端版本选择入口。

老师的资源包保存为 kit-02-v12，自己的开发工程保存在用户目录下 web-work/p1-portfolio。第 2 课起先提交、备份，再导入新课模板，恢复个人内容。不要把老师的资源仓库设置为自己的 origin。

课堂继续按 PPT 推进。PowerShell 标注的课件命令应在 PowerShell 执行；使用 CMD 的学生按 CMD 手册对应步骤操作。HTML、CSS、JavaScript 与 Vue 开发任务一致。
