# PersonaLink 文档中心

每份文档只回答一类问题，避免同一内容反复出现。

面向 HTML 初学者、希望按课时动手学习时，请从项目根目录的 Lecture 教学课程包 开始。

所有 npm 命令的缩写、命名历史和本项目对应关系统一见 npm 命令词典与命名故事。
