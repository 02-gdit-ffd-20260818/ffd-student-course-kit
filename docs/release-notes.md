## p4-v1.3

在线演示：<https://02-gdit-ffd-20260818.github.io/ffd-student-course-kit/>

解决了两个实际用下来最扎眼的问题：

1. **分享链接打开的不是贺卡，是编辑器。** 收到链接的人想看的是一张卡片，
   结果看到一个表单，卡片挤在右边一栏里。现在分享链接进入**阅读模式**：
   整页只有一张贺卡，底下一个「我也要做一张」按钮，标题栏也换成"给某某的祝福"。
2. **生成的文案太单调。** 旧版每个「场景 × 语气」只有一句固定文案，同样的输入
   永远得到同一句话。现在每个组合有三句正文，配三种开头和三种落款，共 810 种说法，
   新增「换一个说法」按钮。文案库 `src/shared/greetingTemplates.js` 由前后端共用。

顺带修掉的：

- 流式分片用的 `/.{1,8}/gu` 里 `.` **不匹配换行符**，多行祝福的换行会被整段吃掉。
- 后端不可用时页面直接报错。现在退回本地文案库出稿，纯静态部署也能完整使用。
