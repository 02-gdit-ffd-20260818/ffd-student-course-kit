## 2. 测试前准备

### 2.1 启动项目

项目需要两个终端窗口。下面命令从项目根目录开始执行，代码块中的 `#` 是命令备注，不需要执行：

```bash
# 终端一：进入后端目录
cd backend

# 按 backend/package-lock.json 安装确定版本的依赖
npm ci

# 启动后端；默认地址为 http://localhost:3003
npm start
```

```bash
# 终端二：进入前端目录
cd frontend

# 按 frontend/package-lock.json 安装确定版本的依赖
npm ci

# 启动 Vite 开发服务器；默认地址为 http://localhost:3000
npm run dev
```

`npm ci` 是按锁文件安装依赖，适合测试和部署；`npm run dev` 是执行 `package.json` 中的开发脚本。两个服务都要保持运行，测试完成后可以在对应终端按 `Ctrl+C` 停止。

### 2.2 测试环境记录

- 前端地址：<http://localhost:3000>
- 后端地址：<http://localhost:3003>
- 数据文件：`backend/db.json`（教学项目，不是真实数据库）
- 测试日期：填写本次实际执行日期
- 测试人员：填写执行人
- 浏览器和版本：填写实际浏览器，例如 Chrome 版本号

### 2.3 测试账号和数据

- 管理员：`admin@system.com / admin123`
- 普通用户：使用注册流程创建一个测试账号。
- 测试前先复制一份 `backend/db.json`；涉及新增、修改、删除时，优先使用测试数据。

Windows 备份命令：

```powershell
# 复制教学数据作为备份；如果当前就在项目根目录，可直接执行
Copy-Item -LiteralPath .\backend\db.json -Destination .\backend\db.json.test-backup
```

Linux/macOS 备份命令：

```bash
# 复制教学数据作为备份
cp backend/db.json backend/db.json.test-backup
```

测试过程中如果修改了数据，不要把备份文件当作正式数据提交到 Git。
