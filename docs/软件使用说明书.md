# PersonaLink 软件使用说明书

> 本手册中的 `npm ci` 是 **clean install**；前端 `npm run dev` 中 **dev = development**。详细原因见 npm 命令词典与命名故事。

## 启动

在两个终端分别运行：

```bash
cd backend
npm ci
npm start
```

```bash
cd frontend
npm ci
npm run dev
```

打开 `http://localhost:3000`。默认管理员：`admin@system.com` / `admin123`。

## 普通用户操作

1. 在注册页填写姓名、邮箱、至少 6 位密码，并选择班级；成功后进入资料页。
2. 在“个人资料”填写个人信息、选择/上传头像并保存。
3. 在“照片墙”浏览同班成员；鼠标悬停照片可放大查看，点击卡片进入详情。
4. 在“搜索”按页面提供的条件查找用户；退出会清除本浏览器保存的登录状态。

## 管理员操作

1. 登录后从首页进入“班级管理”：创建班级；删除前需先处理该班成员。
2. 进入“用户管理”：填写姓名、邮箱、班级并点击“添加用户”。新用户密码为 `123456`。
3. 在用户卡片点击“重置密码”并确认，可恢复普通用户密码为 `123456`；点击“删除用户”将不可恢复。
4. 照片墙中可选择班级，也可选“全部班级”。

## 常见问题

- 页面提示网络错误：确认后端终端仍显示监听 `3003`，再刷新页面。
- 注册没有班级可选：请先用管理员创建班级。
- 删除班级失败：该班仍有成员，先在用户管理中删除或将成员资料改到其他班级。
- 上传头像后 JSON 变大：这是当前教学存储方式的正常现象。
