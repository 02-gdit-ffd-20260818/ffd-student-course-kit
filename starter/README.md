# P1 第 04 课：筛选与排序（学生起步）

本目录是 P1 v1.2.1 的课堂切片。完整功能以同课教师答案为对照；学生在 TODO-L4 处亲手完成本课核心实现。

## 启动

```powershell
npm ci
npm run check:starter
npm run dev
```

在终端显示的本地网址查看。第 1—5 课默认 http://127.0.0.1:5173/，第 6 课以 Vite 输出为准。终端 Ctrl+C 停止。不要双击 HTML 运行模块。

## 完成后验证

```powershell
npm run check:lesson
npm run check
npm test
npm run build
```

学生起步包的 check:lesson 预期不通过，这是待完成任务。部分原有测试也会因 TODO 未完成而失败；先完成课堂任务再做全量验收。check:starter 只确认启动文件，不代表功能完成。

完整任务见试教包中的逐课学生任务单；教师讲法见逐页讲稿。个人资料只使用自己愿意公开的信息。
