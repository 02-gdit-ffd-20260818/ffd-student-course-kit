# P3 v1.0 字段字典

本版本使用虚构教学数据。公开页面只输出白名单字段；授权状态和保留期限只用于发布前检查，不发送给页面组件。

| 字段 | 类型 | 必填 | 用途 | 隐私级别 | 公开条件 |
| --- | --- | --- | --- | --- | --- |
| `id` | string | 是 | 列表稳定标识 | 内部 | 可公开技术标识 |
| `name` | string | 是 | 识别成员 | 公开 | 资料授权 |
| `role` | string | 是 | 发现协作方向 | 公开 | 资料授权 |
| `cohort` | string | 否 | 说明学习群体 | 公开 | 资料授权 |
| `location` | string | 否 | 粗粒度地域连接 | 公开 | 只到城市，不采集住址 |
| `bio` | string | 否 | 了解成员关注点 | 公开 | 单独确认介绍文本 |
| `skills` | string[] | 否 | 发现技能连接 | 公开 | 由成员自报 |
| `interests` | string[] | 否 | 发现兴趣连接 | 公开 | 由成员自报 |
| `avatar` | string | 否 | 增强辨识度 | 公开 | 照片单独授权；失败时显示文字 |
| `profileConsent` | boolean | 是 | 控制整条资料是否公开 | 受限 | 永不公开 |
| `photoConsent` | boolean | 是 | 记录照片授权 | 受限 | 永不公开 |
| `retentionUntil` | date | 是 | 到期复核和删除 | 受限 | 永不公开 |

明确不采集：电话、详细住址、身份证件、私人邮箱、私人社交账号、家庭信息。
