# 第 17 次课教师指南：产品答辩

目标不是介绍技术栈，而是用生产 URL 证明“具体用户在具体场景中完成了什么任务”。每组限时 8 分钟：30 秒用户/问题/价值，3 分钟主任务，1 分钟空与失败恢复，2 分钟反馈与取舍，余下时间提问。

## 教师课前

1. 执行 `npm run smoke:production`，将时间和输出归档。
2. 要求每组只选 P1—P5 中一个主项目，不做功能巡礼。
3. 反馈必须脱敏；至少一条被采纳、一条被拒绝，均要对应 Issue/commit 或明确理由。

## 评分核对（100）

- 用户、问题、价值可验证：25。
- 生产主任务完整且 3 分钟内完成：25。
- 正常、空、失败与恢复真实：20。
- 反馈—修改—验收证据链：20。
- 如实说明未完成项与下一版假设：10。

出现“只有截图没有 URL”“用技术名词代替用户价值”“编造用户反馈”时，对应项不得分。网络临时故障可使用带时间的备用录屏，但仍需现场运行 smoke test 并如实记录。

## 归档模板

记录组别、项目/版本、生产 URL、用户任务、两条反馈、演示结果、评委问题、证据缺口和下一版 Backlog。答辩后不直接修改生产数据。
