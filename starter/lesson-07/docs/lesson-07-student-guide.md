# 第 07 次课学生起点与验收

本课从空仓库和教师提供的 3 篇 mock 数据开始。你需要亲手建立 Vue 项目、组件契约、四种数据状态和 Netlify 发布链。

## 必须完成

1. 画出文章、详情、标签和关于页面的站点地图。
2. 完成 `AppShell`、`ArticleList`、`ArticleCard`、`ArticleDetail`。
3. 至少使用一次 prop、emit、命名 slot 和生命周期。
4. 完成 loading、success、empty、error、not-found 状态。
5. 提交正常、边界、失败三类测试。
6. 推送后让 CI 通过，并提交匿名可访问的 Netlify URL。

## 不允许

- 提交教师 Solution、`node_modules`、`dist` 或真实个人信息。
- 只截图、不提交可运行代码和测试。
- 把失败态替换成浏览器默认报错。
