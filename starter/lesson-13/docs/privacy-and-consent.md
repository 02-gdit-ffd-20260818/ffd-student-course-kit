# P3 隐私与授权说明

## 教学基线

- 仓库中的姓名、经历、头像均为虚构教学数据，不对应真实学生。
- 真实课堂采集前，教师必须说明字段用途、公开范围、保留期限和删除方式。
- 个人介绍与照片分别授权；拒绝照片不影响成员参与课程。
- 成员可以随时撤回授权。收到撤回后，从数据源删除并重新部署，不只是在 CSS 中隐藏。
- 默认保留到课程结束后的下一个月；继续展示必须重新确认。

## 发布前四问

1. 这个字段是否直接帮助“认识成员、发现协作”任务？
2. 页面是否能在没有该字段时正常工作？
3. 当事人是否知道谁可以看到、保留多久？
4. 撤回后能否定位并删除源数据、构建产物和备份中的记录？
