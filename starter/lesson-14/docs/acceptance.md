# P4 验收与版本记录

## User Story

作为想表达心意的用户，我希望生成一段可修改的祝福文案、选择合适的贺卡样式并获得分享链接；即使 AI 暂不可用，我也能得到可用结果并知道当前处于降级模式。

## 版本验收

- v1.0：表单、服务端代理、Prompt v1、人工确认、无密钥 fallback。
- v1.1：三套模板、实时预览、编辑、复制与打印。
- v1.2：SSE 流式状态、12 秒前端超时、8 秒上游超时、限流、安全校验、无数据库分享 URL、密钥扫描。

## 采纳与拒绝

- 采纳服务端代理：浏览器无法读取供应商密钥。
- 采纳 Responses API：使用 `instructions`、`input`、`max_output_tokens`，并设置 `store: false`。
- 采纳确定性 fallback：课堂不依赖付费账号和第三方稳定性。
- 采纳 URL fragment 分享：无需数据库，片段不随 HTTP 请求发送；同时限制长度并提醒隐私。
- 拒绝在前端调用模型：任何“前端环境变量隐藏密钥”的方案都可从构建产物提取。
- 拒绝自动发布模型原文：生成结果必须经过人工确认和编辑。
