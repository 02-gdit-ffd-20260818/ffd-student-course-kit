# P5 验收与版本记录

## User Story

作为课堂主持人，我希望同学可以有序点歌、队列可见可控，音乐来源故障时仍能继续主持，并且所有外部内容都有可检查的来源和许可。

## 版本

- v1.0：Pinia mock 队列、合成音、五态播放器、去重/删除/清空/下一首。
- v1.1：合法来源 Adapter、来源与许可元数据、失败回退。
- v1.2：主持台、锁定、排序、活动日志、每人点歌限流、本地恢复。

## 采用与拒绝

- 采用 Adapter：页面不依赖单一服务字段。
- 采用浏览器生成合成音：无网络也能完成主流程，不引入录音版权。
- 采用 Wikimedia Commons 文件许可页：每条数据均展示来源和许可，公开演示前仍需复核。
- 拒绝抓取第三方音乐平台、绕过防盗链或缓存未授权音频。
- 拒绝强制自动播放：遵守浏览器必须由用户发起播放的限制。
