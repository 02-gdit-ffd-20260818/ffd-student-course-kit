## 操作提示

### 保存失败也要有可用界面

存储可能被限制或写入失败。
try 中尝试写入；catch 返回 saved:false。
无论是否保存，都返回可应用的主题。

### 第一段操作：切换与记忆

完成两个主题函数。
点击切换，刷新页面，再次检查。
指出写入与读取分别在哪里发生。

### fetch 请求的是一个资源

projects.json 是当前站点的静态文件。
fetch 发出请求，await 等待异步结果。
读取响应后，数据再交给页面处理。

```javascript
const response = await fetch("./projects.json")
if (!response.ok) throw new Error("读取失败")
const items = await response.json()
```

### 第二段操作：请求与故障记录

验证正常、空和失败回退。
在 Network 中找到请求路径与状态。
记录一次失败的预期、实际和恢复动作。
