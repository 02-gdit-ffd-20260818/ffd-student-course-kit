## 操作提示

### 模板绑定作品字段

双花括号输出文本。
:href 把表达式绑定到属性。
v-if 决定是否显示有效链接。

### 第一段操作：显示一件作品

完成 props 声明和模板字段绑定。
在卡片中显示名称、简介和技能。
修改一条作品数据，确认页面对应变化。

### 事件报告发生了什么

子组件发出 select，并带上作品 id。
父组件收到 id 后决定怎样更新状态。
事件名称与监听名称需要对应。

```javascript
<button
  type="button"
  @click="$emit('select', project.id)"
>
  记录查看
</button>
```

### 第二段操作：点击与完整卡片

补齐 select 事件按钮。
点击不同卡片，父页面出现对应作品名称。
保留状态、技能、链接等原有显示信息。

### 重构需要回归检查

正常作品列表、筛选、排序。
主题切换与刷新保持。
空数据、请求失败与恢复。
手机布局、打印和链接。
