### 完成名称排序

asc 对应正方向，desc 对应反方向。
比较函数只返回比较结果。
复制与排序都由独立函数承担。

```javascript
export function sortProjects(items, order = "asc") {
  const direction = order === "desc" ? -1 : 1
  const source = Array.isArray(items) ? items : []
  return [...source].sort((a, b) =>
    a.name.localeCompare(b.name, "zh-CN") * direction
  )
}
```
