## 操作提示

### 需要跨列的区块

只有带 wide-card 类的区块跨满两列。
普通区块保持单列宽度。
样式选择器和 HTML 类名必须一致。

### 第一段操作：两种窗口宽度

添加桌面网格与跨列规则。
在 390px 和 1280px 宽度查看。
记录一个发生布局变化的位置。

### 检查点：断点前后发生了什么

小于 700px：使用基础单列布局。
达到 700px：启用新增的网格规则。
浏览器按 CSS 条件匹配，不按设备名称判断。

### 小屏幕减少非必要空间

宽度不超过 420px 时减小区块内边距。
保留文字与边缘的距离。
不通过把字号缩得很小来掩盖溢出。

```javascript
@media (max-width: 420px) {
  .site-header { padding-top: 44px; }
  section {
    padding: 18px;
    border-radius: 12px;
  }
}
```

### 第二段操作：完成打印版本

编写完整 @media print 区块。
清除阴影，调整页宽与间距。
增加长经历，检查分页与链接。

### 测试要覆盖介质

正常：桌面双列，内容层级清楚。
边界：窄屏与长经历仍可阅读。
失败检查：无效作品链接被记录并修复。

## 打印规则参考（配合PPT打印规则页）

先自行写出白底黑字与隐藏跳转控件，再对照以下规则补齐宽度、分页和链接地址。逐条解释后加入styles.css末尾，使用浏览器打印预览检查；不要通过隐藏正文压缩页数。

```css
@media print {
  :root,
  body {
    color: #000;
    background: #fff;
    font-size: 10pt;
  }

  .skip-link {
    display: none;
  }

  .site-header,
  main,
  footer {
    width: 100%;
  }

  .site-header {
    padding: 0 0 12pt;
  }

  main {
    display: block;
  }

  section {
    break-inside: avoid;
    margin: 0 0 10pt;
    padding: 10pt 0;
    border: 0;
    border-top: 1pt solid #777;
    border-radius: 0;
    box-shadow: none;
  }

  a[href^="http"]::after,
  a[href^="mailto"]::after {
    content: " (" attr(href) ")";
    color: #000;
    font-size: 8pt;
    overflow-wrap: anywhere;
  }
}

```

A4纵向先保持默认缩放；检查全部正文、链接和分页。内容增长可能需要多页，优先保证完整可读。自动检查只能确认规则存在，不能替代打印预览。
