## 操作提示

### 技能列表的结构

一个技能作为一个 li。
ul 组织多项并列技能。
类名 tag-list 复用已有样式。

### 第一段操作：完成个人内容

独立完成两个 section。
把 h1 和个人介绍改成自己愿意公开的内容。
增加第三项技能；保存并刷新页面。

### 检查点：结构与显示一致

每人指出自己的 main、h2 和 li。
同桌能在十秒内找到技能和作品入口。
如果区块不出现，检查标签闭合与文件是否保存。

### CSS 盒模型决定间距

content：内容区域。
padding：内容到边框之间的距离。
border：边框。
margin：区块与外部元素的距离。

```javascript
section {
  margin: 18px 0;
  padding: 24px;
  border: 1px solid #cad6e4;
}
```

### 第二段操作：可读与可访问

调整一处间距，并说明原因。
替换作品链接，实际点击检查。
按 Tab 检查键盘焦点能否看见。
缩窄窗口，观察文字是否溢出。
