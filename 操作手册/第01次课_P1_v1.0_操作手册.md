# 第 01 次课｜P1 v1.0｜名片上线操作手册

> 第一次使用 Git/GitHub 的同学：先打开 [小白从空文件夹到公网：完整操作手册](<../../00_小白从空文件夹到公网_完整操作手册.md>)，完整完成第 1、2、4、6 节，再回到本页写页面。不要只执行下面“创建空仓库”一句话。

## 先学知识点

| 知识点 | 小白要理解的话 |
|---|---|
| HTML | 决定页面“是什么”，如标题、段落、链接 |
| 语义标签 | `header/main/section/footer` 能让人和机器理解内容职责 |
| CSS | 决定“长什么样”；选择器找元素，声明设样式 |
| 盒模型 | 一个元素由 content、padding、border、margin 组成 |
| Git | `add` 选择变更，`commit` 保存有说明的版本 |

先读懂这个最小结构：

```html
<section class="card">
  <h2>我的项目</h2>
  <p>这是项目简介。</p>
</section>
```

```css
.card { margin: 16px; border: 1px solid #ccc; padding: 16px; }
```

## 课前准备

确认 `git --version`、`code --version`可用，GitHub 已登录。准备可公开的头像、自我介绍和联系方式，不使用身份证号、家庭住址等隐私数据。

## 分步操作

1. 按小白完整手册第 2 节，在本地创建 `ffd-p1-portfolio`，完成第一次 commit，并连接 GitHub 的真正空仓库。
2. 在 GitHub 仓库的 `Issues` 标签点击 `New issue`，标题写“访客在 30 秒内了解作者和联系方式”，正文写验收条件，点击 `Submit new issue`。随后在本地创建 `index.html`、`styles.css`、`README.md` 和 `assets/`。
3. 先只写 HTML：`header/main/section/footer`，将标题层级按 `h1 → h2` 组织。
4. 用浏览器打开页面，确认不加 CSS 也能按顺序读懂。完成第一次 commit。
5. 补充盒模型、字体、颜色、间距和最大宽度；在 DevTools 中检查 margin/border/padding/content。
6. 为头像写准确 `alt`，确保所有链接可用键盘访问。完成第二次 commit。
7. README 写项目目标、运行方式、页面结构和隐私说明。
8. 配置 GitHub Pages，记录公网 URL，修正线上路径后完成第三次 commit。

## 跟做代码

新建 `index.html`：

```html
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>张三的个人名片</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <header><h1>张三</h1><p>前端开发学习者</p></header>
  <main>
    <section><h2>关于我</h2><p>我正在学习 HTML、CSS 和 JavaScript。</p></section>
    <section><h2>技能</h2><ul><li>HTML</li><li>CSS</li></ul></section>
    <section><h2>联系我</h2><a href="mailto:student@example.com">student@example.com</a></section>
  </main>
  <footer><small>&copy; 2026 张三</small></footer>
</body>
</html>
```

新建 `styles.css`：

```css
* { box-sizing: border-box; }
body { margin: 0; font-family: system-ui, sans-serif; color: #172033; background: #f5f7fb; }
header, main, footer { width: min(720px, calc(100% - 32px)); margin: auto; }
header { padding: 48px 0 24px; }
section { margin: 16px 0; padding: 20px; background: white; border: 1px solid #d8dfeb; border-radius: 12px; }
a { color: #0759b7; }
a:focus-visible { outline: 3px solid #ffbf47; outline-offset: 3px; }
footer { padding: 24px 0; }
```

在 VS Code 中右键 `index.html` 选择 **Open with Live Server**。看到白色卡片、标题和可点击邮箱即成功。

## 检查与提交

- 正常：首页可读，联系链接可访问。
- 边界：32 字长姓名、200% 缩放时不遮挡。
- 失败：头像移除后仍有替代文本。
- 提交：URL、README、至少 3 次有意义 commit、v1.0 Release。

## 常见故障

Pages 404 时检查发布分支、`index.html` 位置和文件名大小写；本地正常而线上图片失效时，检查相对路径和 Git 是否已跟踪图片。
