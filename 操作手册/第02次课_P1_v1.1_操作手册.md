# 第 02 次课｜P1 v1.1｜可投递履历操作手册

## 先学知识点

- **Flex**：适合一行或一列的对齐；`gap` 控制间距。
- **Grid**：适合同时有行和列的卡片区。
- **移动优先**：先写小屏基础样式，大屏再用 `min-width` 增强。
- **可访问性**：语义顺序、键盘焦点、对比度不能只靠“看起来”。

## 课前准备

拉取 P1 v1.0，确认公网 URL 可访问。新建 `feature/responsive-resume` 分支，用 DevTools 记录一个现有布局问题。

## 分步操作

1. 画出移动端单列和桌面端双列草图，先确定阅读顺序再写 CSS。
2. 使用 Flex 完成一维对齐，用 Grid 完成项目卡片布局；能说明为什么选择它。
3. 采用移动优先样式，只在内容确实需要时增加媒体查询，不为某个设备型号写断点。
4. 检查正文字号、行高、对比度、焦点样式和链接文案。
5. 添加 `@media print`，隐藏导航/交互控件，保留姓名、技能、项目和联系方式。
6. 用 375 px、768 px、1440 px 三个视口互测，再用打印预览检查 A4 分页。
7. 修正后合并 PR，发布 v1.1。

## 跟做代码

把以下内容追加到 `styles.css`，并将 `.resume` 改成你页面的主容器类名：

```css
.resume { display: grid; gap: 16px; }
.skills { display: flex; flex-wrap: wrap; gap: 8px; }
.skills li { padding: 6px 10px; border-radius: 999px; background: #e8f1ff; }
@media (min-width: 768px) { .resume { grid-template-columns: 1fr 2fr; align-items: start; } }
@media print {
  nav, button { display: none !important; }
  body { background: white; color: black; font-size: 11pt; }
  .resume { display: block; }
  section { break-inside: avoid; border: 0; box-shadow: none; }
}
```

按 `F12` 切换 375/768/1440 px，再按 `Ctrl+P` 看 A4 预览。四个场景都无横向滚动即通过。

## 检查与提交

- 没有水平滚动条，不靠固定高度撑布局。
- Tab 键可看到焦点，20 字长技能标签不溢出。
- 提交移动/桌面/打印证据、互测问题与修复 commit。

## 常见故障

出现横向滚动时，在 DevTools 逐层查找超宽元素，优先检查固定宽度、长文本和图片 `max-width`，不要直接用 `overflow:hidden` 掩盖问题。
