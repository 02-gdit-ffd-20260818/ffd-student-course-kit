# 第 03 次课｜P1 v1.2.0｜数据化操作手册

## 先学知识点

- `const` 表示变量不再指向新值；`let` 用于需重新赋值的变量。
- 数组是一组有顺序的值，对象用“字段: 值”表示一个事物。
- `for...of` 逐个取出数组元素；函数把重复操作变成可复用步骤。
- DOM 是浏览器中的页面对象，`querySelector` 用 CSS 选择器找元素。

## 课前准备

复习 `const/let`、字符串、布尔值、数组下标和 `console.log`。打开 `06_代码案例/01_js_dom`作为结构参考，不整段复制。

## 分步操作

1. 把一张项目卡片抽象为对象，确定 `id/name/summary/skills/url` 字段及类型。
2. 创建 `data.js`，定义至少 3 个项目；用 `console.table` 检查数据。
3. 先用 `for...of` 循环输出项目名，确认循环和下标；再封装 `renderProjects(items)`。
4. 获取列表容器，根据数组生成卡片。数组为空时显示明确空态。
5. 添加一个基础交互（显示/隐藏详情或技能筛选），事件处理函数不超过一个职责。
6. 故意造成变量名错误，通过 Console 读取错误类型、文件和行号，将定位过程记入 Bug 记录。
7. 完成正常/空数组/字段缺失测试并发布 v1.2.0。

## 跟做代码

`index.html` 准备 `<section id="projects"></section><script type="module" src="app.js"></script>`。

```js
// data.js
export const projects = [
  { id: 1, name: '一页知我', summary: '个人主页', skills: ['HTML', 'CSS'] },
  { id: 2, name: '交互简历', summary: '可投递履历', skills: ['JavaScript'] },
  { id: 3, name: '作品门户', summary: 'Vue 作品集', skills: ['Vue'] },
]
```

```js
// app.js
import { projects } from './data.js'
const root = document.querySelector('#projects')
function renderProjects(items) {
  root.innerHTML = items.length
    ? items.map(item => `<article><h2>${item.name}</h2><p>${item.summary}</p></article>`).join('')
    : '<p>暂无项目</p>'
}
console.table(projects)
renderProjects(projects)
```

用 Live Server 打开，看到 3 张卡和 Console 表格即成功。改为 `renderProjects([])` 检查空态。

## 常见故障

ES Module 因 `file://` 受限时，用 Live Server 或本地 HTTP 服务器打开；`Cannot read properties of null` 时检查选择器和脚本加载时机。
