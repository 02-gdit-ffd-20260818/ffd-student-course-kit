# 第 04 次课｜P1 v1.2.1｜筛选排序操作手册

## 先学知识点

- **纯函数**：同样输入得到同样输出，不偷偷改外部数据。
- `filter` 保留符合条件的项，`map` 转换每一项，`sort` 会修改原数组。
- `[...items]` 创建浅副本；`Set` 用于去重；`export/import` 用于模块化。

## 课前准备

确保 P1 v1.2.0 的项目数组和渲染函数已可用。在 Issue 中写清筛选条件、排序字段和同值时规则。

## 分步操作

1. 写纯函数 `filterProjects(items, skill)`，传入全部时返回新数组，不改动原数据。
2. 写 `sortProjects(items, order)`，先复制数组再 `sort`，说明为什么避免直接改原数组。
3. 用 `Set` 或数组累积生成技能选项，不在 HTML 中重复维护标签。
4. 将数据、选择逻辑、渲染逻辑分成模块，使用明确的 `export/import`。
5. 连接筛选和排序控件，任意一个控件变化后都从原数据重新计算视图。
6. 在 Console 直接调用核心函数，验证全部、单技能、无匹配、升序和降序。
7. 将手写实现与 Agent 建议变体对比，只采用能解释且通过测试的部分。

## 跟做代码

```js
// projectService.js
export function filterProjects(items, skill) {
  return skill === 'all' ? [...items] : items.filter(item => item.skills.includes(skill))
}
export function sortProjects(items, order = 'asc') {
  return [...items].sort((a, b) => {
    const result = a.name.localeCompare(b.name, 'zh-CN')
    return order === 'asc' ? result : -result
  })
}
export function collectSkills(items) {
  return [...new Set(items.flatMap(item => item.skills))]
}
```

```js
// app.js 中的组合部分
function updateView() {
  const filtered = filterProjects(projects, document.querySelector('#skill').value)
  renderProjects(sortProjects(filtered, document.querySelector('#order').value))
}
document.querySelector('#skill').addEventListener('change', updateView)
document.querySelector('#order').addEventListener('change', updateView)
```

HTML 需有 `id="skill"` 和 `id="order"` 的两个 `select`。连续切换后原数组不变即成功。

## 检查与提交

连续切换筛选不丢数据；同名项目顺序稳定；空结果有提示。提交函数输入/输出说明、测试表、PR 和 v1.2.1。

## 常见故障

排序后原顺序无法恢复，通常是直接对原数组使用了 `sort`；模块 404 时检查相对路径、`.js` 后缀和大小写。
