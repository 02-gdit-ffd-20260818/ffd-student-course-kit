# 第 05 次课｜P1 v1.2.2｜交互记忆操作手册

## 先学知识点

- 事件是用户或浏览器的动作，如 `click/submit/change`。
- `localStorage` 保存字符串；对象需用 `JSON.stringify/parse`。
- `fetch` 连上服务器不代表 HTTP 成功，仍要检查 `response.ok`。
- 交互必须显示 loading/success/empty/error，不让用户猜。

## 课前准备

列出复制联系方式、主题切换、反馈表单和 mock 数据四条用户操作路径，为每条写成功与失败反馈。

## 分步操作

1. 用 `querySelector` 精确获取控件，用 `addEventListener` 绑定事件，禁止在 HTML 中写内联事件。
2. 实现复制按钮：成功后改变按钮文案；Clipboard API 失败时给可操作提示。
3. 用 `data-theme` 控制主题，用 `localStorage` 保存；首次打开采用系统偏好，刷新后恢复用户选择。
4. 为表单设置 `label`、必填项和长度限制，提交前 `trim`，错误文案放在对应字段附近。
5. 将 mock JSON 放入单独文件，用 `fetch`、`response.ok`、`try/catch` 区分加载、成功、空数据和失败。
6. DevTools Network 切换 Offline，确认页面不会永久停在 loading。
7. 清除 Storage、刷新、重复提交、输入超长文本，记录结果并发布 v1.2.2。

## 跟做代码

HTML 增加 `<button id="theme">切换主题</button><button id="copy" data-value="student@example.com">复制邮箱</button><p id="message" role="status"></p>`。

```js
const message = document.querySelector('#message')
document.documentElement.dataset.theme = localStorage.getItem('theme') || 'light'
document.querySelector('#theme').addEventListener('click', () => {
  const next = document.documentElement.dataset.theme === 'dark' ? 'light' : 'dark'
  document.documentElement.dataset.theme = next
  localStorage.setItem('theme', next)
})
document.querySelector('#copy').addEventListener('click', async event => {
  try {
    await navigator.clipboard.writeText(event.currentTarget.dataset.value)
    message.textContent = '复制成功'
  } catch {
    message.textContent = '复制失败，请手动复制'
  }
})
```

CSS 增加 `[data-theme="dark"] { color-scheme: dark; background: #172033; color: white; }`。切换后刷新，主题保留即成功。

## 常见故障

`fetch` 本地 JSON 失败时使用 HTTP 服务器；主题闪烁时在首次渲染前读取存储；不要在 localStorage 中保存密码或 Token。
