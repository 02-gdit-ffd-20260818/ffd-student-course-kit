# 第 06 次课｜P1 v2.0｜Vue 门户操作手册

## 先学知识点

- **Vite** 负责开发服务器和生产构建；**Vue** 用数据描述界面。
- `.vue` 文件由 `<script setup>`、`<template>`、`<style>` 组成。
- `ref` 创建响应式值；`v-for` 遍历；`:prop` 传值；`@event` 听事件。
- 父组件管数据，子组件接受 prop 并 emit 用户意图。

## 课前准备

运行 `node -v`，应为 24.x。备份 P1 v1.2.2 线上 URL，在新分支中进行重构，不覆盖可用旧版。

## 分步操作

1. 使用 `npm create vite@latest` 创建 Vue 项目，运行 `npm install` 和 `npm run dev`，识别 `package.json/src/public/index.html`。
2. 先用纸笔画组件树：App、Header、Profile、ProjectList、ProjectCard、Footer，为每个组件写单一职责。
3. 迁移 HTML 时优先保持语义和视觉一致，不同时大规模改版。
4. 把项目数据放入 `ref`，用 `v-for` 和稳定 `:key`渲染；用 `v-if/v-else` 表示空态。
5. `ProjectCard` 用 props 接收数据，用 emit 通知父组件，不直接修改 prop。
6. 迁移 CSS 并检查样式作用域，保留原版移动端和打印能力。
7. 执行 `npm run build`，对比 v1.2.2 与 v2.0 的功能清单，通过 PR 合并和部署。

## 跟做代码

可直接使用 `06_代码案例/02_vue_component`：

```powershell
# 从教学资源包根目录进入 Vue 组件示例。
cd .\06_代码案例\02_vue_component
# 按锁文件精确安装示例依赖。
npm ci
# 启动 Vite 开发服务器；出现 Local 地址后用浏览器打开。
npm run dev
```

`components/ProjectCard.vue`：

```vue
<script setup>
defineProps({ project: { type: Object, required: true } })
const emit = defineEmits(['open'])
</script>

<template>
  <article>
    <h2>{{ project.name }}</h2>
    <p>{{ project.summary }}</p>
    <button @click="emit('open', project.id)">查看</button>
  </article>
</template>
```

`App.vue` 中用 `<ProjectCard v-for="item in projects" :key="item.id" :project="item" @open="openProject" />`。修改数据时页面自动更新，点击按钮可获得 id 即成功。最后运行 `npm run build`。

## 检查与提交

开发服务器无 Console 错误；数据更改会驱动视图；构建生成 `dist`。提交组件树、关键 props/emit 说明、新旧回归表、PR 和 v2.0 URL。

## 常见故障

`npm` 不可用时重开终端并检查 Node PATH；组件不显示时检查 import 路径、组件名和 Console；不要把 `node_modules` 提交到 Git。
