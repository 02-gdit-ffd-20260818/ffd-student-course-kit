# 第 07 次课｜P2 v1.0｜博客阅读端操作手册

## 先学知识点

- **prop** 是父传子的数据，子组件不直接修改。
- **emit** 是子组件向父组件报告事件。
- **slot** 让父组件填入一段模板内容。
- 数据页面至少考虑 loading、empty、success 和 not-found。

## 课前准备

建立 P2 仓库和 Issue，准备 3 篇短文、标签和摘要的 mock JSON。不使用未授权文章、图片或真实隐私数据。

## 分步操作

1. 画出“文章列表 → 文章详情 → 标签结果 → 关于”站点地图。
2. 设计 `ArticleCard` props，区分必需/可选字段，用 emit 输出用户意图。
3. 用 `ArticleList` 组合卡片，实现正常、空列表和加载三种视图。
4. 在详情组件中展示标题、时间、正文和标签；对未找到文章给出返回入口。
5. 使用插槽实现可复用页面框架，能说明插槽与 prop 各适合什么内容。
6. 通过生命周期记录数据加载时机，避免在模板中写复杂业务逻辑。
7. 走完两条阅读路径，修正空态和长文本后发布 v1.0。

## 跟做代码

`components/ArticleCard.vue`：

```vue
<script setup>
defineProps({ article: { type: Object, required: true } })
defineEmits(['open'])
</script>
<template>
  <article class="card">
    <h2>{{ article.title }}</h2>
    <p>{{ article.summary }}</p>
    <button @click="$emit('open', article.id)">阅读全文</button>
  </article>
</template>
```

`App.vue` 的最小列表：

```vue
<script setup>
import { ref } from 'vue'
import ArticleCard from './components/ArticleCard.vue'
const articles = ref([{ id: 1, title: '第一篇', summary: '学习 Vue 组件' }])
const selected = ref(null)
</script>
<template>
  <main>
    <h1>长风成卷</h1>
    <p v-if="articles.length === 0">暂无文章</p>
    <ArticleCard v-for="item in articles" :key="item.id" :article="item" @open="selected = item" />
    <section v-if="selected"><h2>{{ selected.title }}</h2><p>{{ selected.summary }}</p></section>
  </main>
</template>
```

看到文章卡片，点“阅读全文”后出现详情即成功。

## 检查与提交

列表到详情的主路径完整；空数据和错误 id 可恢复。提交站点地图、组件契约、空态截图和 v1.0 URL。

## 常见故障

prop 更改警告表明子组件在修改父数据，改为 emit；列表状态串行时将 loading/empty/error 条件按互斥顺序整理。
