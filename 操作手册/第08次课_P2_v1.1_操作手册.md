# 第 08 次课｜P2 v1.1｜博客管理端操作手册

## 先学知识点

- Router 把 URL 映射到页面；`/articles/:id/edit` 中 `id` 是动态参数。
- `v-model` 连接输入框与状态；computed 根据已有状态计算新值。
- Pinia store 保存跨组件共享状态；action 统一修改数据。
- CRUD 分别是 Create、Read、Update、Delete。

## 课前准备

确保 P2 v1.0 可运行，在 Issue 中写清新建、编辑、删除、搜索、草稿和预览的验收标准。

## 分步操作

1. 安装 Vue Router 和 Pinia，为阅读端、管理列表、编辑和预览设计路由表。
2. 配置动态路由 `:id`，刷新详情页仍能根据路由恢复文章。
3. 用 `v-model`、`trim`、必填和长度规则建立文章表单；错误展示在字段附近。
4. 用 computed 派生搜索结果，只在需要执行副作用时用 watch。
5. 在 Pinia store 中统一定义文章数组和 CRUD action，组件不各自保存独立副本。
6. 删除前二次确认，给出取消路径；草稿不出现在阅读端。
7. 测试直接刷新编辑页、删除后返回、空搜索和误删取消，发布 v1.1。

## 跟做代码

```powershell
# 在当前 P2 项目中安装 Vue Router 和 Pinia，并写入 package.json/package-lock.json。
npm install vue-router@latest pinia@latest
```

`src/router.js`：

```js
import { createRouter, createWebHistory } from 'vue-router'
import ArticleList from './views/ArticleList.vue'
import ArticleForm from './views/ArticleForm.vue'
export default createRouter({ history: createWebHistory(), routes: [
  { path: '/admin/articles', component: ArticleList },
  { path: '/admin/articles/new', component: ArticleForm },
  { path: '/admin/articles/:id/edit', component: ArticleForm, props: true },
] })
```

`src/stores/articles.js`：

```js
import { defineStore } from 'pinia'
export const useArticleStore = defineStore('articles', {
  state: () => ({ items: [] }),
  actions: {
    save(article) {
      const index = this.items.findIndex(item => item.id === article.id)
      index >= 0 ? this.items.splice(index, 1, article) : this.items.push({ ...article, id: Date.now() })
    },
    remove(id) { this.items = this.items.filter(item => item.id !== id) },
  },
})
```

在 `main.js` 中依次 `app.use(createPinia()).use(router).mount('#app')`。访问 `/admin/articles/new`，保存后列表数量增加即成功。

## 常见故障

刷新路由 404 时区分开发服务器与生产托管的 SPA fallback；computed 不更新时检查是否破坏了响应式引用。
