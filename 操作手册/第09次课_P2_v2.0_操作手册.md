# 第 09 次课｜P2 v2.0｜REST 前后端联调操作手册

> 不熟悉本地启动、终端端口或 Git 收尾时，先看 [小白完整操作手册第 4、5、9 节](<../../00_小白从空文件夹到公网_完整操作手册.md>)。

## 先学知识点

- HTTP 请求有方法、URL、请求头和请求体；响应有状态码和响应体。
- GET 查询，POST 新建，PUT/PATCH 更新，DELETE 删除。
- 2xx 成功，4xx 是客户端/权限问题，5xx 是服务器未处理故障。
- `async/await` 等待 Promise；`try/catch/finally` 管理成功、失败和收尾。

## 课前准备

运行 `06_代码案例/03_express_blog`。准备 REST Client/Postman/Apifox 之一，画出浏览器—HTTP—Express 请求路径。

## 分步操作

1. 写 API 契约：方法、路径、请求 JSON、成功响应和 400/404/500 错误响应。
2. Express 启用 `express.json()`，先完成 `/health`、GET 列表和 POST 新建。
3. 对标题做类型、空值和长度校验，不相信前端已校验。
4. 在 `.http` 文件中保存正常、空标题和错误 id 请求，记录状态码。
5. 前端封装 API 函数，使用 `async/await` 和 `try/catch/finally`切换 loading/success/empty/error。
6. 从 mock 切换到真实 API，核对字段和时序；在 Network 面板查看请求头、负载和响应。
7. 关闭 API 再操作前端，验证失败提示和重试入口，通过 CI 后发布 v2.0。

## 跟做代码

```powershell
# 从教学资源包根目录进入 Express 博客 API 示例。
cd .\06_代码案例\03_express_blog
# 按锁文件精确安装后端依赖。
npm ci
# 启动开发服务；终端持续运行表示服务正在监听。
npm run dev
```

新建 `api.http` 并用 REST Client 点击 **Send Request**：

```http
GET http://127.0.0.1:3000/health

###
GET http://127.0.0.1:3000/api/articles

###
POST http://127.0.0.1:3000/api/articles
Content-Type: application/json

{"title":"我的新文章"}
```

前端 API 函数：

```js
export async function listArticles() {
  const response = await fetch('http://127.0.0.1:3000/api/articles')
  if (!response.ok) throw new Error(`HTTP ${response.status}`)
  return response.json()
}
```

GET 返回数组、POST 返回 201 和新 id 即成功。把 POST 标题改为空字符串，应看到 400。

## 检查与提交

GET/POST 联调成功；非法输入返回 4xx 而不是 500；断网可恢复。提交 API 契约、`.http` 文件、Network 证据、smoke test 和 v2.0。

## 常见故障

CORS 问题先确认前后端域名/端口和服务器许可源；`req.body` 为空时检查 JSON 中间件与 `Content-Type`。
