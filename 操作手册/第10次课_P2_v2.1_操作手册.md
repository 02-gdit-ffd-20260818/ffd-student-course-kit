# 第 10 次课｜P2 v2.1｜数据持久化操作手册

> 第一次接触数据库时，先看 [小白完整操作手册第 12 节](<../../00_小白从空文件夹到公网_完整操作手册.md>)，明确 SQLite 文件、MySQL 密钥和备份都不能随代码覆盖或上传。

## 先学知识点

- 表存一类事物；行是一条记录；列是字段。
- 主键唯一识别行；外键连接两张表；约束阻止非法数据。
- SQL CRUD 是 `INSERT/SELECT/UPDATE/DELETE`；应先 SELECT 确认范围再 UPDATE/DELETE。
- 备份只有实际恢复并校验后才可信。

## 课前准备

按环境指南准备 SQLite CLI 或 SQLite Viewer。复习表、行、列、主键、外键和约束的含义。

## 分步操作

1. 从文章和评论业务规则提取实体、字段和关系，画简化 ER 图。
2. 在 `schema.sql` 中建 users/articles/comments，设置主键、非空、唯一、默认值和外键。
3. 执行 `.read schema.sql`和 `.schema`，确认建表可重现；开启 `PRAGMA foreign_keys=ON`。
4. 编写 seed 数据，手工练习 SELECT/INSERT/UPDATE/DELETE，每次先用 SELECT 确认范围。
5. 在服务器数据层使用参数化语句，不拼接用户输入；将 SQL 错误转为稳定 API 错误。
6. 实现查询、分页和总数，检查负数页码、超大 pageSize 和空结果。
7. 复制数据库文件作为备份，删除测试记录后从备份恢复，比对表数量和关键数据。

## 跟做代码

按环境指南安装 SQLite，然后在资源包根目录执行：

```powershell
# 用课程 schema.sql 初始化本地 blog.db；只对当前目录数据库生效。
sqlite3 blog.db ".read 06_代码案例/04_database/schema.sql"
# 列出数据库表，确认 schema 已成功创建。
sqlite3 blog.db ".tables"
# 插入一个仅用于课堂的测试用户。
sqlite3 blog.db "INSERT INTO users(email) VALUES('student@example.com');"
# 为编号 1 的测试用户插入一篇测试文章。
sqlite3 blog.db "INSERT INTO articles(author_id,title,content) VALUES(1,'第一篇','正文');"
# 查询文章关键字段，确认数据已经持久化。
sqlite3 blog.db "SELECT id,title,status FROM articles;"
```

预期 `.tables` 显示 `users articles comments`，SELECT 显示“第一篇”。备份与恢复：

```powershell
# 在删除演练前，把当前 blog.db 完整备份为 blog-backup.db。
sqlite3 blog.db ".backup blog-backup.db"
# 故意删除测试库文章，用来验证恢复能力；不得对生产数据库执行。
sqlite3 blog.db "DELETE FROM articles;"
# 从刚才的备份恢复当前测试库。
sqlite3 blog.db ".restore blog-backup.db"
# 统计恢复后的文章数量；应与删除前一致。
sqlite3 blog.db "SELECT count(*) FROM articles;"
```

最后输出 `1` 表示恢复成功。`blog.db` 和备份不要提交到 Git。

## 检查与提交

重启 API 后数据仍在；非法外键被拒绝；备份可恢复。提交 ER/Schema、迁移/seed、CRUD 结果和恢复记录，不提交含真实数据的 `.db`。

## 常见故障

`foreign key constraint failed` 时检查父记录与删除顺序；`database is locked` 时关闭额外 GUI/CLI 连接并缩短事务。
