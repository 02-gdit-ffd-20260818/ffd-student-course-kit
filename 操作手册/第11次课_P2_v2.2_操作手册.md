# 第 11 次课｜P2 v2.2｜生产版操作手册

> 学生不登录生产服务器。教师先按 [小白完整操作手册第 11 节](<../../00_小白从空文件夹到公网_完整操作手册.md>) 完成只读体检，再使用本课教师 runbook 演示发布与回滚。

## 先学知识点

- 认证回答“你是谁”，授权回答“你能做什么”。
- 密码应做带 salt 的强哈希，不明文保存；前端隐藏按钮不等于授权。
- 环境变量把密钥与代码分离；Nginx 把 HTTPS/静态文件/API 请求转给对应服务。
- health check 只回答服务是否可用，不泄露配置。

## 课前准备

备份数据库，确认域名/服务器/托管平台访问权限。复制 `env.example` 但不填写或提交真实密钥。

## 分步操作

1. 画出访客、作者、管理员权限矩阵，默认拒绝，不只在前端隐藏按钮。
2. 密码只保存强哈希；登录失败返回统一信息，不泄露账号是否存在。
3. 为受保护 API 增加服务器端身份与权限校验，直接请求 API 也不得越权。
4. 上传检查文件大小、MIME/内容、扩展名和生成文件名，禁止任意路径。
5. 将前端/API/数据库/反向代理画成部署图，配置生产环境变量和 HTTPS。
6. 参考 `05_CI-CD/nginx-spa-api.conf`配置 SPA fallback 与 `/api/` 反代，确认不暴露 `.env` 和数据库文件。
7. 执行登录、越权、上传、健康检查和回滚演练，保存最小必要的脱敏日志。

## 跟做代码

服务器启动前强制检查 Secret：

```js
const required = ['SESSION_SECRET']
for (const name of required) {
  if (!process.env[name]) throw new Error(`Missing environment variable: ${name}`)
}

function requireRole(role) {
  return (req, res, next) => {
    if (!req.user) return res.status(401).json({ message: 'login required' })
    if (req.user.role !== role) return res.status(403).json({ message: 'forbidden' })
    next()
  }
}

app.delete('/api/articles/:id', requireRole('admin'), deleteArticle)
app.get('/health', (req, res) => res.json({ ok: true }))
```

本地 PowerShell 临时配置：

```powershell
# 只为当前 PowerShell 会话设置本地开发密钥；关闭窗口后失效，不能用于生产。
$env:SESSION_SECRET='local-development-only-change-me'
# 按 package.json 的 start 脚本启动本地 P2 API。
npm start
# 在另一个 PowerShell 窗口执行 health 检查脚本；不要在被 npm start 占用的窗口继续输入。
node .\06_代码案例\07_health_check\check.mjs
```

未登录调删除接口应得 401，非管理员得 403，`/health` 得 `{"ok":true}`。生产环境从平台 Secret 设置，不使用这个示例值。

## 检查与提交

提交生产 URL、部署图、权限矩阵、健康/越权测试、日志片段和回滚证据；截图前遮蔽 Token、Cookie、IP 和个人数据。

## 常见故障

直接刷新 404 检查 Nginx SPA fallback；API 502 检查进程、端口和反代目标；不要为排错把 Secret 打印到日志。
