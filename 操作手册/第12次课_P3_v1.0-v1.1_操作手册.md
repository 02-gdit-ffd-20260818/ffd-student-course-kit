# 第 12 次课｜P3 v1.0—v1.1｜画像与可视化操作手册

## 先学知识点

- 字段字典说明数据名、类型、用途、是否必填和隐私级别。
- 聚合是把多条明细计算成分组统计；图表数据应由原数据计算。
- 柱状图适合比较类别，折线图适合时间趋势，饼图只适合少量占比。
- ECharts 需要有明确宽高的 DOM 容器。

## 课前准备

准备 6—10 条虚构/经授权成员数据。在采集前写字段目的、是否公开、保留时间和删除方式。

## 分步操作

1. 建立字段字典，只保留展示/图表必需字段；隐私字段不采集。
2. 用卡片组件展示头像、姓名/昵称、技能和简介，图片设定尺寸、`alt`和失败占位。
3. 实现关键字与技能筛选，对空值、大小写和无结果做处理。
4. 先用纸笔回答“图表要回答什么问题”，再按分类比较/占比/趋势选择合适图型。
5. 写数据聚合函数，先在 Console 核对计数，再将结果传入 ECharts，不手写另一份图表数据。
6. 为图表提供标题、单位、tooltip 和文本摘要；容器尺寸变化时调用 resize。
7. 使用含空技能、失效图片和超长简介的数据测试，完成 v1.0 画像和 v1.1 图谱发布。

## 跟做代码

```powershell
# 在当前 P3 项目安装 ECharts，并同步更新依赖清单与锁文件。
npm install echarts@latest
```

Vue 组件：

```vue
<script setup>
import * as echarts from 'echarts'
import { onMounted, onBeforeUnmount, ref } from 'vue'
const chartEl = ref(null)
const members = [{ skills: ['Vue', 'CSS'] }, { skills: ['Vue', 'Node'] }, { skills: [] }]
const counts = members.flatMap(m => m.skills).reduce((all, skill) => {
  all[skill] = (all[skill] || 0) + 1
  return all
}, {})
let chart
function resize() { chart?.resize() }
onMounted(() => {
  chart = echarts.init(chartEl.value)
  chart.setOption({ title: { text: '技能分布' }, xAxis: { type: 'category', data: Object.keys(counts) }, yAxis: { type: 'value' }, series: [{ type: 'bar', data: Object.values(counts) }] })
  window.addEventListener('resize', resize)
})
onBeforeUnmount(() => { window.removeEventListener('resize', resize); chart?.dispose() })
</script>
<template><div ref="chartEl" style="height: 360px"></div></template>
```

预期图表显示 Vue=2、CSS=1、Node=1。如空白，先检查容器是否有 `height`。

## 检查与提交

列表与图表来自同一份数据；空值不会导致 `NaN`；手机端可阅读。提交字段字典、授权说明、聚合校验、图表和 v1.1。

## 常见故障

图表空白时检查容器是否有高度、数据是否为数值和是否在 DOM 就绪后初始化；页面卡顿时不在模板中重复做聚合。
