# 第 13 次课｜P3 v2.0｜成员管理与数据导入操作手册

> 本课成果：完成成员状态流转、角色权限校验和 CSV 数据导入。先读知识点，再逐项复制代码；每完成一步都立即验证。

## 先学知识点

| 知识点 | 小白理解 | 本课用在哪里 |
|---|---|---|
| 状态机 | 状态只能沿规定路线变化，不能随便跳 | 待审核只能变为通过或驳回 |
| RBAC | 根据角色决定能做什么 | 只有审核员可审批成员 |
| 后端校验 | 前端限制不可靠，服务端必须再检查 | 阻止越权和非法状态 |
| 事务 | 一组数据库操作要么全成功，要么全撤销 | 批量导入成员 |
| CSV 注入 | 以 `= + - @` 开头的单元格可能被表格软件执行 | 导入、导出前清洗 |

记住执行顺序：**识别用户 → 检查权限 → 校验数据 → 写入数据 → 返回结果**。

## 跟做代码

将以下代码保存为 `workflow-demo.mjs`：

```js
const allowedNext = {
  draft: ['submitted'],
  submitted: ['approved', 'rejected'],
  approved: [],
  rejected: ['submitted']
}

function changeStatus(member, nextStatus, currentUser) {
  if (currentUser.role !== 'reviewer') {
    throw new Error('无审批权限：需要 reviewer 角色')
  }

  const allowed = allowedNext[member.status] ?? []
  if (!allowed.includes(nextStatus)) {
    throw new Error(`非法流转：${member.status} 不能变为 ${nextStatus}`)
  }

  return { ...member, status: nextStatus, updatedBy: currentUser.name }
}

function safeCell(value) {
  const text = String(value ?? '').trim()
  return /^[=+\-@]/.test(text) ? `'${text}` : text
}

const member = { id: 1, name: safeCell('小林'), status: 'submitted' }
const reviewer = { name: '王老师', role: 'reviewer' }

try {
  const result = changeStatus(member, 'approved', reviewer)
  console.log('审批成功：', result)
} catch (error) {
  console.error('审批失败：', error.message)
  process.exitCode = 1
}
```

运行：

```powershell
# 运行当前目录的审核工作流演示脚本，观察提交、审核和发布状态变化。
node workflow-demo.mjs
```

成功时应看到 `status: 'approved'`。若看不到，先确认文件名和终端所在目录，再检查英文引号与括号是否成对。

## 检查与提交

- 普通成员审批返回 403；审核员可审批。
- 非法状态跳转返回 400，并说明当前状态和目标状态。
- 错误 CSV 不写入数据库；正确 CSV 给出成功条数。
- 提交状态图、权限矩阵、接口结果截图、导入报告和 commit SHA。

## 常见故障

- **按钮隐藏了仍能直接调接口**：后端没有做角色校验。
- **导入一半后失败**：应使用事务，发生错误时回滚整批。
- **中文乱码**：CSV 保存为 UTF-8；读取时明确使用 UTF-8。
- **重复审批**：先检查当前状态，必要时增加版本号或更新时间校验。
