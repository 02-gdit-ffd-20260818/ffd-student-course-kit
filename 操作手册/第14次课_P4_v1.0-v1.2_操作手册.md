# 第 14 次课｜P4 v1.0-v1.2｜AI 代理与降级操作手册

> 本课成果：完成“前端请求自己的后端、后端再调用 AI”的安全链路，并在未配置密钥、超时或上游失败时给出可理解的降级结果。

## 先学知识点

| 知识点 | 小白理解 | 本课用在哪里 |
|---|---|---|
| Prompt | 给模型的任务、背景、限制和输出格式 | 让结果稳定、可验收 |
| Secret | 不能提交到仓库的密钥 | 只放服务端环境变量 |
| 代理接口 | 浏览器不直接接触 AI 密钥 | `/api/greetings/generate` 与 `/api/greetings/stream` |
| 超时 | 请求超过规定时间就主动终止 | 防止页面一直转圈 |
| 降级 | AI 不可用时仍返回可用提示或规则结果 | 无密钥、限流、断网 |

安全链路：`浏览器 → 自己的后端 → AI 服务`。密钥绝不能写入 Vue 文件、浏览器存储或 Git。

## 跟做代码

前端非流式请求的真实最小代码为：

```js
export async function generateGreeting(payload, fetchImpl = fetch) {
  const response = await fetchImpl('/api/greetings/generate', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(payload)
  })
  const data = await response.json().catch(() => ({}))
  if (!response.ok) throw new Error(data?.error?.message || '生成失败，请稍后再试')
  return data
}
```

服务启动后，新建 `ai-test.http`：

```http
GET http://localhost:3000/health

### 正常请求
POST http://localhost:3030/api/greetings/generate
Content-Type: application/json

{
  "receiver": "林老师",
  "occasion": "感谢",
  "tone": "真诚",
  "details": "感谢这一学期的耐心指导"
}

### 空称呼，应返回 400
POST http://localhost:3030/api/greetings/generate
Content-Type: application/json

{
  "receiver": "",
  "occasion": "感谢",
  "tone": "真诚",
  "details": ""
}
```

用 VS Code REST Client 点击 `Send Request`。正常请求应返回 `openai` 或 `fallback` 模式；空称呼必须返回明确的 400，敏感内容返回 422，不能让服务崩溃。

## 常见故障

- **浏览器 CORS 报错**：前端应请求自己的后端，并核对允许的前端来源。
- **一直 loading**：在 `finally` 中关闭 loading，并设置请求超时。
- **提交后才发现密钥泄漏**：立即撤销旧密钥并换新；仅删除文件不能让旧密钥失效。
- **结果格式漂移**：在 Prompt 中写清字段，并在服务端验证返回结构。
