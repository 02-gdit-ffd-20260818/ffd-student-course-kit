# 项目 5：星声音乐站｜三次课唯一总入口

> 教师备课和上课从本页开始。项目目标是做一个课堂点歌与播放系统：搜歌、点歌、排队、播放、切歌、主持人控场。技术上的重点是**接口抽象**和**状态管理**——换一个音源不改业务代码，队列逻辑写成纯函数好测好改。

## 课时安排

本项目设计为 **3 次课**，每次 3 × 45 分钟，编号用 **P5-01 ~ P5-03**，不占用第 1—18 课的编号。

课堂主线目前排的是项目 1—3 加期末三次课，共 18 次。项目 5 是否排进课堂、排几次，由任课教师按实际进度决定；不排课时作为选做加分项或兴趣拓展，资料同样完整可用。

## 两个贯穿始终的设计

### 1. 适配器模式：换音源不改业务代码

```text
                 ┌─ MockMusicAdapter      课堂合成音，浏览器实时生成，不依赖网络
业务代码 → 适配器 ┤
                 └─ LicensedMusicAdapter  公版/CC0 录音，标注来源与许可
```

业务代码只调用 `adapter.search()` 和 `adapter.toQueueItem()`，**完全不知道背后是哪一种音源**。课堂上当场切换音源，页面照常工作——这是讲"面向接口编程"最直观的一次。

### 2. 纯函数：队列逻辑单独拿出来写

队列的增删改查全部写成**纯函数**放在 `queueCore.js` 里：输入什么、输出什么，不碰 Vue、不碰浏览器、没有副作用。

好处是**可以直接用 `node --test` 测试**，不需要启动浏览器，不需要渲染组件。这一条会在第 2 课反复用到。

## 版权边界（每次课都要强调）

课堂点歌系统最容易出问题的地方不是技术，是**版权**。

- 默认音源是 `MockMusicAdapter`，音频由浏览器用 Web Audio **实时合成**，不含任何第三方录音。
- 另一个音源 `LicensedMusicAdapter` 只收录 **CC0 或公有领域**的录音，每一首都带 `license` 和 `sourceUrl` 字段，界面上必须显示出来。
- **不要接入任何商业音乐平台的接口，也不要上传自己收藏的音乐文件。**课堂作品随时可能公开展示。

## 两条学习路线

- **路线 A：继续个人仓库。** 先 `git status` 和 `git pull --ff-only`，再完成本课 TODO。
- **路线 B：本课从零开始。** 直接克隆对应的 `p5-lesson-0X` 分支。

```cmd
git clone --branch p5-lesson-01 --single-branch https://github.com/02-gdit-ffd-20260818/ffd-student-course-kit.git p5-lesson-01
```

**本段命令怎么读**

`git` 管理版本；`status` 查看改动；`diff` 查看逐行差异；`add` 选择待提交文件；`commit -m` 创建本地版本并写说明；`push` 发到远端；`clone` 下载仓库，`--branch` 选择分支，`--single-branch` 只取该分支历史；`remote` 管理远端别名，`fetch` 只取回记录。命令中的 `.` 表示当前目录，`--` 后面是文件路径。推送前用 `git remote -v` 核实 origin 是自己的仓库。

> 三个分支需要在开课前从 `学生起步/` 推到学生模板仓库，详见 `教师开课检查.md`。

### 两条路线在每一课的起点是同一个状态

学生模板是**累进式**生成的：第 N 课的模板挖掉的是第 N 课**以及之后每一课**的 TODO，
第 1 到 N-1 课的代码都是做完的。

带来的结果很实用：

```text
克隆第 N 课模板  ==  做完第 N-1 课之后你自己工程的样子
```

所以路线 A 和路线 B 在每一课开始时拿到的是同一个状态，
手册里「操作前」那一句对两条路线都成立。做完本课 TODO，你的工程就等于下一课的模板。

用 `python 工具/检查双线路衔接.py` 可以随时验证这条性质。

## 项目边界与交付定义

**星声音乐站——协作点歌与播放队列平台**

- **真实用户任务**：一群人一起点歌、排队和播放，规则清楚、互不覆盖
- **版本路线**：v1.0 音源适配与容错；v1.1 队列纯函数与测试；v1.2 限流、版权标注与 CI
- **特别边界**：只用合成音与 CC0/公有领域录音，每首都要标注 license 和来源；不接商业音乐平台接口。

每个版本的共同完成定义（User Story、三类测试、绿色 CI、可访问 URL、备份与回滚……）
不在这里重复，见唯一权威版本：[评分量规与通用清单](../../../通用/07_评分量规与通用清单.md) 的第一节。
