# lesson-13 教师答案

本目录只收录本课 TODO 涉及的完整答案文件，不复制整个项目，也不混入其他课答案。

## 本课任务

1. TODO 01 · 给 users 表加上约束
2. TODO 02 · 班级外键
3. TODO 03 · 让 `db:status` 说清楚库里有什么
4. TODO 04 · 报告里要能看到日志模式

- `backend/src/database.js`

## 使用方法

1. 学生先按《第13课_课堂操作手册.md》独立完成，不要一开始就覆盖文件。
2. 卡住时，先在手册对应 TODO 的“改哪里”处确认文件和位置。
3. 再把学生文件与 `完整答案文件/` 下同路径文件逐段对照。
4. 需要看精确改动时打开 `本课改动.patch`：`-` 是修改前，`+` 是完成后的参考写法。
5. 只改当前 TODO；不要整文件覆盖，以免冲掉学生自己的内容。
6. 按手册“自己验证”执行命令并亲眼确认结果。能运行不等于任务完成。

答案来源：`PersonaLink_SQLite/`。教师修改完整工程后，应运行 `python 工具/生成逐课教师答案.py` 重新生成并检查。
