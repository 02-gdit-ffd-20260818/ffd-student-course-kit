# lesson-11 教师答案

本目录只收录本课 TODO 涉及的完整答案文件，不复制整个项目，也不混入其他课答案。

## 本课任务

1. TODO 01 · 把媒体上传接口打开
2. TODO 02 · 只收白名单里的文件类型
3. TODO 03 · 上线之后要逐条验
4. TODO 04 · 生产环境的配置要单独一份

## 答案文件

- `.env.example`
- `scripts/verify-live.mjs`
- `server/blog-app.js`
- `server/media-upload.js`

## 使用方法

1. 学生先按《第11课_课堂操作手册.md》独立完成，不要一开始就覆盖文件。
2. 卡住时，先在手册对应 TODO 的“改哪里”处确认文件和位置。
3. 再把学生文件与 `完整答案文件/` 下同路径文件逐段对照。
4. 需要看精确改动时打开 `本课改动.patch`：`-` 是修改前，`+` 是完成后的参考写法。
5. 只改当前 TODO；不要整文件覆盖，以免冲掉学生自己的内容。
6. 按手册“自己验证”执行命令并亲眼确认结果。能运行不等于任务完成。

答案来源：`工程基线/`。教师修改完整工程后，应运行 `python 工具/生成逐课教师答案.py` 重新生成并检查。
