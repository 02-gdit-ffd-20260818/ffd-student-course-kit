## 本课在项目 1 里的位置

前三课做的都是**静态**页面：HTML 决定内容，CSS 决定样子，写好就定了，
用户做什么页面都不会变。

这一课第一次让页面**对用户的动作做出反应**——这是 JavaScript 的本职工作。
做完之后，你的主页会多出七样东西：阅读进度条、当前栏目徽标、导航高亮、
点击跟随、返回顶部按钮、滚动联动、栏目淡入。

下一课（第 05 课）会用 JavaScript 把作品列表改成**由数据生成**。
所以这一课要打好的基础是：**怎么拿到页面元素、怎么监听事件、怎么改元素的状态。**

## 开课前先讲这些概念

学生动手之前，先把这几个词讲清楚。每个只讲到"能用自己的话解释"为止，不展开。

|知识点|小白要理解的话|本课在哪里用到|
|---|---|---|
|DOM|浏览器把 HTML 变成的一棵"元素树"。JavaScript 改页面，改的就是这棵树|每个 TODO|
|选择器|和 CSS 里写的一样：`#id` 找一个，`.class` 找一类，`nav a` 找某个范围里的|准备段|
|事件|用户做的动作（点击、滚动、改地址栏），浏览器会"广播"出来|TODO 04、05|
|监听|`addEventListener('事件名', 回调)`——注册一个"发生这件事就执行"的函数|TODO 04、05|
|class 切换|JS 只负责加/去掉类名，**长什么样由 CSS 决定**。两边分工不要混|TODO 03、05、07|
|hash|地址栏 `#` 后面那一段。点 `<a href="#skills">` 就是在改它|TODO 02、04|
|视口|屏幕上"当前能看见"的那一块区域。页面比它高，所以才需要滚动|TODO 01、06、07|
|回调函数|作为参数传给别人、让别人在合适的时候替你执行的函数|TODO 04—07|

### 三个最小例子，本课五个任务都是它们的变形

**例 1：拿到元素并改它**

```html
<button id="hello">点我</button>
```

```js
const button = document.querySelector('#hello')   // 1. 拿到
button.textContent = '我被改了'                    // 2. 改它
```

**例 2：监听事件**

```js
button.addEventListener('click', () => {
  button.textContent = '你点了我'                  // 点击时才执行
})
```

**例 3：加一个类，让 CSS 接管样子**

```css
.is-active { color: red; }
```

```js
button.classList.toggle('is-active', true)        // 加上 → 变红
button.classList.toggle('is-active', false)       // 去掉 → 变回来
```

**这三个例子的分工要讲透**：拿到元素是前提，监听事件决定"什么时候做"，
加类名决定"做什么"——而具体长什么样永远由 CSS 说了算。
本课所有 TODO 都跳不出这三件事。

### 这一步的常见故障

|现象|原因|处理|
|---|---|---|
|`系统找不到指定的路径`|桌面上还没有 `web-work`|上面第 1 步的 `mkdir` 那两行不能跳过|
|`fatal: repository not found`|仓库地址写错，或仓库是私有的|检查用户名和学号；私有仓库要先登录|

## 2. 路线 A：领取本课新增的 app.js

> 路线 B 的模板里这些文件已经有了，**直接跳过本节**。

**第一步：把本课新增的文件领到自己的工程里。**

```text
git remote add course https://github.com/02-gdit-ffd-20260818/ffd-student-course-kit.git
git fetch course p1-l04-standalone-v3.0
git checkout course/p1-l04-standalone-v3.0 -- app.js
```

这三条命令一条也不能少，但它们干的事完全不同，**逐条看一遍再执行**：

**① `git remote add course <网址>`——给教师模板仓库起个代号，不下载任何东西。**

|部分|意思|
|---|---|
|`remote`|远程仓库|
|`add`|新增一个|
|`course`|**你给它起的代号**，随便起都行，本课程统一叫 `course`。以后提到这个仓库就用这三个字母代替那一长串网址|
|后面那串网址|教师模板仓库的地址|

这条命令只往 `.git/config` 里写一行配置，**不联网、不下载、一个文件都不会变**。
整个项目只需要做一次；提示 `remote course already exists` 就是已经做过了，**跳过它**。

**② `git fetch course p1-l04-standalone-v3.0`——把本课分支下载到 `.git` 里，工作目录仍然看不到。**

|部分|意思|
|---|---|
|`fetch`|取回|
|`course`|从哪个仓库取——就是①起的那个代号|
|`p1-l04-standalone-v3.0`|取哪一个分支。只取这一个，仓库里其它几十个分支不会碰|

**这一步最容易被误解**：命令跑完之后你去 `dir`，会发现 `app.js` **还是不存在**。
这不是失败。`fetch` 只把内容下载进 `.git` 这个"仓库数据库"里存着，
**没有写到你看得见的工作目录**。取回来的东西在本地叫 `course/p1-l04-standalone-v3.0`（代号/分支名）。

**③ `git checkout course/p1-l04-standalone-v3.0 -- app.js`——真正把文件写出来的一步。**

|部分|意思|
|---|---|
|`checkout`|这里的意思是"从某个版本里取出文件，写进工作目录"|
|`course/p1-l04-standalone-v3.0`|从哪个版本取——就是②取回来的那个|
|`--`|分隔符，意思是"**后面全是文件名，不是分支名**"。不写它的话，万一有个分支恰好也叫 `app.js`，git 就不知道你指的是哪个了|
|`app.js`|要取的文件，只取这一个|

**那是不是只会拿到 `app.js`？**
**是的。** 工作目录里只会多出你点名的这一个文件。
②那一步确实把整个分支的内容都下载到 `.git` 里了，但③只把你写在 `--` 后面的文件写出来，
分支里的其它文件一个都不会冒出来，**你自己改过的 `index.html`、`styles.css` 也不会被覆盖**。

顺带一提：`checkout` 取出来的文件会自动进入暂存区（相当于已经 `git add` 过了），
所以本课末尾直接 `git commit` 就能把它提交上去。

**第二步：确认文件真的到手了，再往下走。**

```text
dir app.js
```

看到文件名和大小才算领到。**没看到就不要继续**，先按下面「领取失败怎么办」处理。

**第三步：在 `index.html` 里加上引用。**

打开 `index.html`，在 `</body>` 之前加上：

```html
<script src="app.js"></script>
```

路线 B 的模板里这一行是写好的；**路线 A 是你自己上一课的作品，里面没有，需要你自己加。**
已经有了就不要重复加。

浏览器从上往下解析。脚本放在最后，执行时页面元素才已经存在，`document.querySelector` 才找得到东西。

### 领取失败怎么办

| 现象 | 原因 | 处理 |
|---|---|---|
| `remote course already exists` | 之前加过了 | 跳过第一条命令，直接执行 `git fetch` 和 `git checkout` |
| `couldn't find remote ref` | 分支名打错了 | 对照上面的 `p1-l04-standalone-v3.0`，一个字符都不能差 |
| `fatal: unable to access` 或卡住 | 连不上 GitHub | 换网络重试；仍然不行用下面的网页兜底 |
| 命令看起来成功，但第二步找不到文件 | 不在工程根目录执行 | 先 `cd` 到自己的工程目录，那里应该有 `index.html` |

文件名保持不变：

### 为什么不双击打开 HTML

双击打开时，浏览器地址栏是 `file:///E:/.../index.html`；

|  |双击打开（file 协议）|本地服务器（http 协议）|

|改完代码|**要自己按 `Ctrl+R` 刷新**|**自动刷新**|

**从第一课就用服务器，把这类坑一次性避掉。**

`app.js` → `updateProgress` 函数里 → 标着 **`← 改这一行`** 的那一行：

```js
progressBar.style.width = '0%' // ← 改这一行
```

**把右边的 `'0%'` 换成**

```js
`${ratio * 100}%`
```

> **注意是反引号 `` ` ``，不是单引号 `'`。**
> 反引号在键盘左上角，`Esc` 下面、数字 1 左边那个键。

**这叫模板字符串**：反引号里面的 `${...}` 会被替换成变量的值。

```js
const ratio = 0.35
`${ratio * 100}%`   // 得到字符串 "35%"
'ratio * 100%'      // 得到字符串 "ratio * 100%" —— 单引号里的东西不会被计算
```

**上面那两行已经写好了，但要看懂**

```js
const scrollable = document.documentElement.scrollHeight - window.innerHeight
const ratio = scrollable > 0 ? window.scrollY / scrollable : 0
```

算法就一句话：**已经滚过的距离 ÷ 能滚的总距离 = 读了百分之多少**。

|写的|意思|
|---|---|
|`documentElement.scrollHeight`|整个文档有多高|
|`window.innerHeight`|窗口有多高|
|两者相减|**能滚的总距离**（文档比窗口高出来的那部分）|

第二行的 `scrollable > 0 ? ... : 0` 是在防一件事：
**页面太短时根本滚不动，`scrollable` 是 0，除以 0 会得到 `NaN`**，
进度条就再也不动了，而且不报错——**这种不报错的 bug 最难查**。

> **凡是分母可能为 0 的地方，都要先挡一下。** 这条以后会反复用到。

**操作前 / 操作后**

- 操作前：顶部那条线**永远是 0 宽，看不见**。
- 操作后：**往下滚，线跟着变长**；滚到底时铺满整个屏幕宽度。

1. 保存，往下滚 → 顶部的线跟着长。

3. **F12 → Elements**，找到 `<div id="reading-progress">`，


回车，应该打印 `'42%'`。

**这一课不要求你会写它们**，但页面上最好看的两个效果正是它俩做的，
所以花五分钟读懂在做什么。

### 第一段：往下滚，高亮自己跟着换

TODO 04、05 做完之后，**点导航**会高亮。但如果你是**用鼠标滚轮往下滚**呢？
这一段就是解决这个的：滚到哪个栏目，导航和徽标自己跟着变，**不用点**。

```js
const spy = new IntersectionObserver(
  entries => { ... },
  { rootMargin: '-45% 0px -45% 0px' },
)
sections.forEach(section => spy.observe(section))
```

一句话解释：**`IntersectionObserver` 是浏览器内置的"监视器"**——
告诉它盯哪些元素，这些元素进出屏幕时它主动通知你。

|这一行|在做什么|
|---|---|
|`new IntersectionObserver(回调, 选项)`|造一个监视器|
|`spy.observe(section)`|让它盯住某个栏目|
|`entry.isIntersecting`|这个栏目现在在屏幕里吗|
|`rootMargin: '-45% 0px -45% 0px'`|**把判定范围上下各收窄 45%**，只剩屏幕中间一条|

**为什么要收窄？** 不收窄的话，栏目**刚露个头**就切换，
往下滚时高亮会来回乱跳。收窄之后意思变成"**滚到屏幕正中间才算进入这个栏目**"。

**可以现场试一下**：把 `-45%` 改成 `0%`，保存，滚一滚 ——
你会看到高亮抖得很厉害。**试完改回 `-45%`。**

### 第二段：栏目进入屏幕时淡入上移

```js
const reveal = new IntersectionObserver(
  (entries, observer) => { ... },
  { threshold: 0.15 },
)
```

还是同一个工具，**但换了一组参数，效果完全不同**：

|  |第一段（滚动高亮）|第二段（淡入）|
|---|---|---|
|什么时候算"进入"|滚到屏幕正中间|**露出 15% 就算**|
|进入之后|继续盯着|**`unobserve` 不再盯了**（只淡入一次）|

> **同一个工具，换一组参数就是另一种效果。**
> 这在编程里非常常见，比"又学一个新 API"值钱得多。

### 为什么这两段不让你写

这一课要掌握的是 `querySelector` / `addEventListener` / `classList` /
`textContent` 这**四样基础**——它们是所有前端交互的地基，
掌握了就能做出页面上的大部分效果。

`IntersectionObserver` 很好用，但它是**进阶 API**，
在你还没把基础用熟之前写它，只会变成照抄。

> **看懂和写得出是两回事。** 这一课先保证你看懂；
> 等基础扎实了，再回头写它就是十分钟的事。

## 常见问题

### 报错类

|Console 里的报错|原因|处理|
|---|---|---|
|`Cannot read properties of null (reading 'style')`|选择器写错，元素没拿到|检查 `#reading-progress` 等 id 和 `index.html` 里的是否一致|
|`navLinks.forEach is not a function`|用了 `querySelector` 而不是 `querySelectorAll`|取集合必须用 `querySelectorAll`|
|`showCurrent is not defined`|函数名拼错，或写在了使用它的代码后面|JavaScript 区分大小写；`function` 声明可以在后面，但要拼对|
|`Uncaught SyntaxError`|少了括号、引号或大括号|看报错提示的行号，往前找一两行|
|404 找不到 app.js|`index.html` 里没有引用，或文件名拼错|见第 2 节第三步|

### 效果不对类

|徽标显示 `undefined`|`|| ''` 兜底没写|`sectionNames.get(current) || ''`|
|徽标一直不出现|`textContent` 拼成了 `textcontent`|JavaScript 区分大小写|
|点导航页面会跳，但高亮不动|只做了 TODO 03，没做 TODO 04|补上 `hashchange` 监听|
