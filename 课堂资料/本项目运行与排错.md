## 统一桌面目录

项目根目录固定为：

```text
C:\Users\自己的用户名\Desktop\web-work\p2-blog
```

`%USERPROFILE%`是CMD中的“当前Windows用户文件夹”；`$HOME`是PowerShell中的同一个位置。两者都会自动适配学生自己的用户名。

## 两种上课起点

- **继续个人项目**：进入`Desktop\web-work\p2-blog\my-blog`，先执行`git status`，确认上次修改已经提交，再执行`git pull`。
- **本课从零开始**：克隆本课独立分支到`Desktop\web-work\p2-blog\lesson-XX`。缺课、上次未完成或个人工程损坏时选择这一条。

不要把本课模板覆盖到其他课次文件夹中。

## Trae IDE与终端

在Trae中选择“文件→打开文件夹”，打开本课`lesson-XX`或个人`my-blog`文件夹。选择“终端→新建终端”：

- 终端A运行`npm.cmd run dev`，保持网页服务运行。
- 第09—11课终端B运行`npm.cmd run dev:api`，保持API运行。
- 终端C运行测试、数据库命令和Git命令。

服务运行时不能在同一个终端继续输入命令。按`Ctrl+C`停止服务，或者切换到另一个终端。

## 通用命令解释

- `cd /d`：CMD同时切换盘符和目录。
- `Set-Location`：PowerShell切换目录。
- `mkdir`、`New-Item`：建立文件夹，不删除已有内容。
- `git clone --branch lesson-XX --single-branch 仓库地址 目标目录`：只领取指定课次，目标目录会自动生成。
- `node --version`：应显示24.x。
- `npm.cmd ci`：严格按照`package-lock.json`安装依赖。
- `npm.cmd run dev`：启动Vue网页开发服务器。
- `npm.cmd run dev:api`：启动Express后端。
- `npm.cmd test`：运行自动测试。
- `npm.cmd run build`：生成可部署的`dist`目录。
- `git status`：查看哪些文件发生变化。
- `git diff`：查看尚未提交的代码差异。
- `git add .`：暂存当前工程的修改。
- `git commit -m "说明"`：生成一个本地版本。
- `git push`：上传到学生自己的远程仓库。

## 首次建立个人远程仓库

在GitHub或Gitee新建一个空仓库，不自动创建README。随后在自己的工程目录执行：

```text
git init -b main
git add .
git commit -m "建立项目2内容发布平台"
git remote add origin 自己仓库的HTTPS地址
git push -u origin main
```

教师模板仓库只用于领取，不作为学生`push`的目标。

## 常见错误

- 找不到`package.json`：当前目录不对，先执行`cd`或`Set-Location`进入本课工程。
- `npm`脚本策略错误：在Windows使用`npm.cmd`。
- 5173或3000端口占用：找到仍在运行的旧终端并按`Ctrl+C`。
- 网页能开但API失败：第09—11课要同时启动网页和API两个服务。
- 数据重启后消失：检查`.env`中的`DATABASE_PATH`，确认没有使用临时数据库。
- `git push`被拒绝：先运行`git remote -v`，确认远程是学生自己的仓库。
