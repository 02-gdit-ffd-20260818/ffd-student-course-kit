## 2. 常用命令

```cmd
REM 安装依赖（本地开发）
npm install
REM 严格按 lock 文件安装（CI 用）
npm ci

REM 启动开发服务器，5173
npm run dev

REM 项目自检
npm run check
REM 只跑纯函数单元测试，几十毫秒
npm run test:unit
REM 只跑组件测试
npm run test:component
REM 两种一起跑
npm test
REM 构建静态产物到 dist/
npm run build
```

<!-- COMMAND_HELP:BEGIN -->
**本段命令怎么读**

`npm` 管理项目依赖并执行脚本；`install` 安装依赖（有兼容的锁文件时使用锁定版本）；`ci` 严格按锁文件安装并重建 node_modules；`run 名称` 执行当前 package.json 的 scripts 中同名命令；`test` 是运行测试脚本。先确认终端所在目录有本课 package.json。服务启动后持续占用终端是正常的，另开终端做下一步，Ctrl+C 才停止服务。
<!-- COMMAND_HELP:END -->


**排错时优先跑 `npm run test:unit`**，它最快，而且大部分逻辑错误都能抓到。

## 4. 两层测试怎么选

| | 单元测试 | 组件测试 |
|---|---|---|
| 命令 | `npm run test:unit` | `npm run test:component` |
| 测什么 | 纯函数：队列、限流、适配器 | 渲染结果：许可有没有显示、面板对不对 |
| 速度 | 几十毫秒 | 几百毫秒 |
| 什么时候用 | **默认用这个** | 只有"界面上到底显示了什么"才用 |

**能用纯函数测的就不要用组件测。**这也是为什么队列逻辑要单独写进 `queueCore.js`。

## 5. Git 标准流程

```cmd
REM 先看改了什么
git status
REM 确认 node_modules、dist 都不在列表里
git add .
git commit -m "P5第X课：一句话说明本次改动"
git push origin main
```

<!-- COMMAND_HELP:BEGIN -->
**本段命令怎么读**

`git` 管理版本；`status` 查看改动；`diff` 查看逐行差异；`add` 选择待提交文件；`commit -m` 创建本地版本并写说明；`push` 发到远端；`clone` 下载仓库，`--branch` 选择分支，`--single-branch` 只取该分支历史；`remote` 管理远端别名，`fetch` 只取回记录。命令中的 `.` 表示当前目录，`--` 后面是文件路径。推送前用 `git remote -v` 核实 origin 是自己的仓库。
<!-- COMMAND_HELP:END -->


第一次推到个人仓库：

```cmd
git remote add origin <你的仓库地址>
git branch -M main
git push -u origin main
```

### 绝对不能提交的东西

```text
node_modules/   依赖，npm install 能装回来
dist/           构建产物，npm run build 能生成
```

这个项目没有 `.env`，也没有任何密钥。

### 一个会被 CI 抓到的坑：文件名大小写

Windows 不区分大小写，`import './RequestPolicy.js'` 引用 `requestPolicy.js` 在本机照样能跑。
**Linux 区分大小写**，CI 在 Ubuntu 上跑，立刻报 `Cannot find module`。

改文件名时用 `git mv` 而不是在资源管理器里改，Git 才能正确记录大小写变化。

## 6. CI/CD

GitHub Actions 的完整入门见 `../../01_入门与通用规范/05_CI-CD与部署配置.md`。

## 9. 通用排错

|现象|原因|处理|
|---|---|---|
|`node -v` 不是 v24|装了别的版本|重装 Node 24 LTS，关掉所有终端重开|
|5173 被占用|上次的进程还在|关掉旧终端，或按 Vite 提示换端口|
|页面白屏|代码有语法错误|看终端**第一条**报错，从第一条开始改|
|点播放没声音|浏览器要求先有用户交互|先点一下页面任意位置；检查系统音量|
|改了代码页面不更新|文件没保存，或改的不是当前工程|Ctrl+S；确认 Trae 打开的是自己的工程|
|依赖树坏了|各种奇怪报错|删掉 `node_modules` 后重新 `npm install`|
|本地绿、CI 红|文件没提交，或路径大小写不对|`git status` 看漏提交；检查 import 路径大小写|
